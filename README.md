# 🍃 Leaf Pest AI – Smart Plant Disease & Pest Detection System

An AI-powered web application that detects plant leaf diseases and pest infections using Deep Learning and Computer Vision techniques. The system helps farmers, researchers, and agricultural professionals identify crop issues early and improve plant health management.

---

## 🚀 Project Overview

Leaf Pest AI is designed to analyze images of plant leaves and predict possible diseases or pest attacks using a trained deep learning model. The application provides a simple and user-friendly interface where users can upload a leaf image and instantly receive prediction results.

This project combines:
- Artificial Intelligence (AI)
- Deep Learning
- Computer Vision
- Agriculture Technology (AgriTech)

The goal is to support smart farming and precision agriculture by enabling fast and accurate crop disease detection.

- 📸 Upload leaf images for analysis

## ⚙️ Installation & Setup

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/aadityasinha048/Leaf_Pest-AI.git
```

### 2️⃣ Navigate to the Project Folder

```bash
cd Leaf_Pest-AI/leaf-pest-detector
```

### 3️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

### 4️⃣ Run the Application

```bash
python app.py
```

### 5️⃣ Open in Browser

```bash
http://127.0.0.1:5000
```

## 📸 How It Works

1. User uploads a leaf image
2. Image preprocessing is performed
3. AI model analyzes the image
4. Disease or pest prediction is generated
5. Result is displayed on the web interface
